# Запуск проекта на Mac с GitHub

Инструкция подходит для macOS и запуска локального веб-интерфейса с веб-камерой Mac. Она не устанавливает программу непосредственно в прошивку Hikvision.

## 1. Скачайте проект

Откройте Terminal и выполните:

```bash
cd ~/Documents
git clone https://github.com/AToPu-sys/person-following-nvidia.git
```

Если папка уже скачана, пропустите `git clone` и перейдите в неё:

```bash
cd ~/Documents/person-following-nvidia
```

Репозиторий приватный. На новом Mac GitHub может попросить войти в аккаунт, которому предоставлен доступ.

## 2. Установите зависимости

Выполняйте команды из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Первый запуск может занять несколько минут. Модель позы `yolo11n-pose.pt` загрузится автоматически при старте приложения.

## 3. Запустите панель

```bash
python -m uvicorn web_app:app --host 127.0.0.1 --port 8080
```

Оставьте окно Terminal открытым и перейдите в браузере по адресу:

```text
http://127.0.0.1:8080
```

При первом запуске приложение создаёт логин `operator` и случайный пароль. Пароль показывается в Terminal один раз и сохраняется в локальном файле `.env`. Посмотреть его можно командой из папки проекта:

```bash
grep '^DASHBOARD_PASSWORD=' .env
```

Не отправляйте пароль в чат и не публикуйте файл `.env`.

## Если порт 8080 занят

Остановите предыдущий сервер сочетанием **Control+C**. Если он всё ещё занят, запустите приложение на 8081:

```bash
python -m uvicorn web_app:app --host 127.0.0.1 --port 8081
```

Тогда откройте `http://127.0.0.1:8081`.

## Разрешите доступ к веб-камере

В macOS откройте **Системные настройки → Конфиденциальность и безопасность → Камера** и разрешите доступ приложению Terminal. Если Terminal отсутствует в списке, закройте и снова запустите его после первого старта приложения.

Для выхода остановите сервер сочетанием **Control+C**.

## Камера Hikvision

Эта инструкция запускает приложение на Mac и использует встроенную веб-камеру. Текущая версия не устанавливается непосредственно в Hikvision. Для прямой установки нужна точная модель камеры, поддержка HEOP и отдельный пакет приложения для совместимой модели. Для просмотра RTSP-потока с IP-камеры потребуется отдельная настройка источника и разрешение на доступ к потоку.
